# Examples for icon-gen

## Installation

```
$ npm install
```

## Usage

`js` is JavaScript. `ts` is TypeScript, executed directly by Node.js (type stripping, Node.js 24 or later).

Generate from SVG.

```
$ npm run js:svg
$ npm run ts:svg
```

Generate from PNG.

```
$ npm run js:png
$ npm run ts:png
```
